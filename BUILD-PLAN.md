### 19. Animation direction

**Principer:** Långsamt, tungt, exakt — som en premiumbil. Aldrig studsigt.

**Easing:**
- Standard: `power3.out` / CSS `cubic-bezier(0.22, 1, 0.36, 1)`
- Filmiska övergångar: `expo.inOut`
- Mikrointeraktioner: `power2.out`, 0.35–0.5 s

**Timing:**
- Rubrikavslöjanden: 1.0–1.2 s, stagger 0.04 s per tecken / 0.08 s per ord.
- Sektionsövergångar: styrs av scroll (scrub), inte av tid.
- Siffror i stats: 1.6 s count-up, `power2.out`.

**Signaturrörelser:**
1. **Hero-skrubbning:** filmen följer scrollen bildruta för bildruta.
2. **Rubriker som avslöjas bakom mask:** rad för rad, underifrån.
3. **Bildavslöjanden:** `clip-path: inset()` som öppnas från mitten, samtidigt som bilden skalar från 1.15 till 1.
4. **Röd linje som ritas:** under aktiva CTA:er och i scroll-indikatorn.
5. **Sticky stack:** pelarkorten staplas på varandra med skalning (1 → 0.92) och mörkning.
6. **Marquee:** orter som glider oändligt, långsammare vid hover.

**Tillgänglighet:** `prefers-reduced-motion: reduce` → inga scrubs, inga parallaxer, inga marquees; innehållet visas direkt. Hero visar en stillbild (poster) med första rubriken.

- **Knappar:** Pill-form. Primär: bruten vit bakgrund, svart text, röd pil som glider 4px vid hover, mjuk röd glöd bakom. Sekundär: glas med tunn linje.
- **Magnetiska knappar (desktop):** CTA följer muspekaren upp till 8px.
- **Anpassad markör (endast desktop med fin pekare):** liten ring som växer över länkar och visar "Räkna" över priskalkylator-knappar. Döljs på touch.
- **Länkar:** understrykning som ritas från vänster.
- **Kort:** lyft 4px, ljus som följer muspekaren (radiell gradient via CSS-variabler).
- **Före/efter-reglage:** dra med mus eller finger, tangentbordsstyrt via `input[type=range]`.
- **Navigation:** transparent i hero, blir grafit med blur efter hero. Döljs vid scroll nedåt, visas vid scroll uppåt. Mobil: helskärmsmeny med stora länkar som glider in.
- **Fokus:** synlig röd fokusring på allt interaktivt.

### 21. Scroll behavior

- **Lenis** för mjuk scroll (`lerp: 0.09`, `smoothWheel: true`). Kopplas till GSAP-ticker så att ScrollTrigger och Lenis går i takt.
- **ScrollTrigger** för all scroll-driven animation.
- **Hero:** `pin: true`, `end: "+=300%"`, `scrub: 0.6`. Tidslinjen driver bildrutorna och de tre textkapitlen.
- **Stats:** triggas en gång vid 75 % synlighet.
- **Mission:** ord tänds från 20 % till 100 % opacitet i takt med scroll (scrub).
- **Pelare:** sticky stack, varje kort pinnas tills nästa täcker det.
- **Service-steg:** horisontell scroll (pinnad sektion, x-förflyttning = innehållets bredd − skärmbredd) på desktop ≥ 1024px.
- **Ankarlänkar:** går via `lenis.scrollTo()`.
- **Uppdatering:** `ScrollTrigger.refresh()` efter att typsnitt och första bildrutor har laddats.

### 22. Mobile behavior

**Hero-skrubbning — bildsekvens på canvas (vald metod):**
Videoskrubbning via `video.currentTime` hackar i Safari och på mobil, så hero använder en bildsekvens:
1. Extrahera ur `Hero-med-bil.mp4` med ffmpeg i **12 bilder/s → 240 bildrutor**.
   - Desktop: 1600 px bred WebP, kvalitet ~68 (mål: < 60 kB/bild, ~12 MB totalt, laddas progressivt).
   - Mobil: 9:16-beskärning 720×1280 WebP, kvalitet ~60, **var 2:a bildruta (120 st, mål < 3 MB)**. Fokuspunkt per kapitel: kapitel 1 vänster-mitt (bilen), kapitel 2 mitten, kapitel 3 mitten.
2. Ladda prioriterat: bildruta 1 först (och som `<link rel="preload">`), därefter var 8:e, var 4:e, sist resten. Skrubba alltid till närmaste laddade bildruta.
3. Rita på `<canvas>` med `object-fit: cover`-logik och `devicePixelRatio` begränsat till 2.
4. Poster: `hero-poster.jpg` visas innan canvas är klar, och för `prefers-reduced-motion`.

**Övriga videor:** `muted playsinline loop preload="none"` + poster. Startas/pausas med `IntersectionObserver`.

**Bilder:** WebP med JPG-fallback via `<picture>`, `loading="lazy"` och `decoding="async"` utanför första skärmen, explicita `width`/`height` mot layoutskift.
